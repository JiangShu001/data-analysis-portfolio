# 电商用户行为转化漏斗分析



## 项目背景



基于淘宝2017年用户行为数据，分析用户从浏览到购买的转化漏斗，找出流失最严重的环节，为产品优化提供数据支持。



## 数据说明



- 来源：阿里天池 - 淘宝用户行为数据集

- 时间范围：2017年11月25日 - 2017年12月3日

- 数据量：约1亿条行为记录

- 字段：用户ID、商品ID、类目ID、行为类型（pv/cart/fav/buy）、时间戳

- 原始数据未上传（文件过大），请从阿里天池下载：https://tianchi.aliyun.com/dataset/649



## 分析目标



1. 分析用户从浏览到购买的转化漏斗

2. 找出流失最严重的环节

3. 给出产品优化建议



## 分析方法



- 工具：Python（pandas、matplotlib）、Power BI

- 核心指标：转化率、流失率

- 分析维度：行为漏斗、用户级漏斗

- 数据清洗：删除缺失值、重复行、异常时间戳



## 核心发现



- 清洗前1亿行，清洗后9,891万行（删除1.2%异常数据）
- 浏览用户：984,080
- 加购用户：737,393
- 购买用户：670,370
- 浏览→加购转化率：74.93%，流失25.07%
- 加购→购买转化率：90.91%，流失9.09%
- **主要流失在"浏览→加购"环节**


## 优化建议



1. 优化商品详情页，提升浏览→加购转化

2. 加购后发送提醒/优惠券，降低加购→购买流失

3. 对加购未购买用户，做定向召回
